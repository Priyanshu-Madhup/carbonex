# Assets Folder

## Place Your Logo Here

**Put your `carbonex.png` file in this folder.**

**Path:** `x:\carbon\carbonex\src\assets\carbonex.png`

### Logo Specifications:
- **Format:** PNG (with transparent background recommended)
- **Size:** 40x40px to 200x200px (will be displayed at 40x40px)
- **File name:** Must be exactly `carbonex.png` (lowercase)

### What This Logo Replaces:
The logo will replace the 🌿 emoji in all navbars across:
- Home page (App.js)
- Dashboard
- Recommendations page
- Organization Setup page

### After Adding the Logo:
1. Save your `carbonex.png` file in this folder
2. Restart the React development server if it's running
3. The logo will automatically appear in all navbars
